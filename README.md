# Консольный калькулятор
## Назначение проекта
Программа представляет собой простейший калькулятор на языке Python, обладающий ограниченным количеством используемых функций и ограниченным количеством чисел, поступающих на ввод.
Он позволяет выполнить одну арифметическую операцию над двумя числами и вывести результат.
## Возможности программы
Программа поддерживает следующие операции:
- `+` — сложение;
- `-` — вычитание;
- `*` — умножение;
- `/` — обычное деление;
- `//` — целочисленное деление;
- `%` — остаток от деления;
- `^` — возведение в степень.
Также программа:
- проверяет корректность ввода чисел;
- проверяет правильность введённой операции;
- обрабатывает деление на ноль;
- выводит результат вычисления.
## Инструкция по запуску
1. Установить Python.
2. Открыть проект в PyCharm.
3. Создать файл `calculator.py`.
4. Вставить в файл программный код.
5. Запустить программу.
6. Ввести первое число.
7. Ввести арифметическую операцию.
8. Ввести второе число.
9. Получить результат.
