# Консольный калькулятор

## Назначение проекта

Программа представляет собой консольный калькулятор на языке Python. Она позволяет выполнять арифметические операции над двумя числами и выполнять несколько вычислений подряд без повторного запуска программы.

## Возможности программы

Программа поддерживает следующие операции:

- `+` — сложение;
- `-` — вычитание;
- `*` — умножение;
- `/` — обычное деление;
- `//` — целочисленное деление;
- `%` — остаток от деления;
- `^` — возведение в степень.

Также программа:

- позволяет выполнять несколько вычислений подряд;
- проверяет корректность ввода чисел;
- проверяет правильность введённой операции;
- обрабатывает попытку деления на ноль;
- проверяет ответ пользователя о продолжении работы;
- завершает работу по команде `нет`.

## Инструкция по запуску

1. Установить Python.
2. Открыть проект в PyCharm.
3. Открыть файл `Калькуляторпитомчик.py`.
4. Запустить программу.
5. Ввести первое число.
6. Выбрать арифметическую операцию.
7. Ввести второе число.
8. Просмотреть результат вычисления.
9. Ввести `да`, чтобы выполнить следующую операцию, или `нет`, чтобы завершить программу.

## Пример работы

```text
=== Консольный калькулятор ===
Доступные операции: +, -, *, /, //, %, ^

Введите первое число: 15
Введите операцию (+, -, *, /, //, %, ^): *
Введите второе число: 4
Результат: 60.0

Хотите выполнить ещё одну операцию? (да/нет): да

Введите первое число: 100
Введите операцию (+, -, *, /, //, %, ^): /
Введите второе число: 4
Результат: 25.0

Хотите выполнить ещё одну операцию? (да/нет): нет
Работа программы завершена.
```
